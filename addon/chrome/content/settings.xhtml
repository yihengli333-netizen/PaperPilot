数据说明：PaperPilot 仅把你选定论文的正文文本发送到你在此配置的模型服务；不会发送你的笔记、其他文献或账号信息。使用本地模型（Ollama 等）时请求不出本机。

模型服务

默认使用 CCG API 中转站，一般无需修改。也可填其他 OpenAI 兼容接口。
在 CCG API 控制台创建令牌后粘贴到这里。
密钥保存在本机 Zotero 配置中，不会写入笔记或同步内容。
选择推荐模型会自动填入；也可直接填写其他模型。填好密钥后可读取该密钥能用的全部模型。

输出与行为

自动：短论文约 3-5 条，中等篇幅 5-8 条，长论文 7-12 条，由模型按贡献点和实验数量决定。
超出时先略去参考文献、致谢和附录，再按章节重要性压缩（方法、结果、结论优先），结果中会给出提示。上限应小于模型的上下文长度。
选中条目后在条目面板自动生成总结；关闭则需手动点击生成。
