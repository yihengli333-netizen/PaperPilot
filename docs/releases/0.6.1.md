# PaperPilot 0.6.1

选中论文，在 PaperPilot 面板生成总结后点击 **导出增强批注 PDF（含导图）**，即可生成一个独立 PDF 附件：句子高亮、建议片段下划线、中文分析批注、阅读说明、分类书签和导图附页。原始 PDF 保留。

## 安装

1. 从本 Release 下载 `paperpilot-0.6.1.xpi`。
2. Zotero → 工具 → 插件/附加组件 → 齿轮 → Install Add-on From File，选择 XPI 后重启。
3. 在 PaperPilot 设置中填写模型端点、密钥和模型。
4. 如需增强 PDF，安装 Python 依赖 `python -m pip install pypdf==6.18.1 reportlab==5.0.1`，在设置里填写该 Python 的完整路径。普通导出和独立导图无需 Python。

## 修复

- 修复插件启动时 rootURI 未定义及 XPI 内 Python 脚本读取失败。
- Python 改用 Unicode 异步调用，支持中文路径，并提供超时、错误报告和临时文件清理。
- 修复 PDF 颜色、透明度和小数坐标；逐行标注避免跨栏涂满，新增中文分析批注和明确外观流。
- 增强 PDF 以新附件保存，保留原文、已有文库批注和原书签；导图追加到末页，原文页码不变。
- 修复 XPI 打包与验证；Python 回归测试加入完整测试流程。
