# PaperPilot 0.7.0

本版重点是标得更准、标得更全：长论文的方法和实验不再被截掉，引用匹配能容忍 PDF 排版差异和模型的个别改词，每个类别可以标出更多原文。增强批注 PDF 不再需要 Python。

## 安装

1. 从本 Release 下载 `paperpilot-0.7.0.xpi`。
2. Zotero → 工具 → 插件/附加组件 → 齿轮 → Install Add-on From File，选择 XPI 后重启。
3. 设置 → PaperPilot → 点“获取密钥”，在 CCG API 控制台创建令牌并粘贴，点“测试连接”。端点和模型已预设。

0.6.x 需要手动安装这一次；从 0.7.0 起，Zotero 可以通过本仓库 Release 中的 `updates.json` 自动更新。

## 改进

- **默认接入 CCG API 中转站**：端点默认为 `https://ccg-cli.online/v1/chat/completions`，模型默认 `doubao-seed-2.0-lite`，学生只需填密钥。设置页新增“获取密钥”（打开控制台）、“获取可用模型”（按当前密钥列出可选模型）和“恢复默认”。旧版中从未填过密钥、仍是 OpenAI 默认值的配置会自动切到中转站；已经配置了密钥的不受影响。仍可填写其他 OpenAI 兼容接口。
- **长论文按章节压缩**：超出字数上限时，先略去参考文献、致谢和附录，再按章节重要性分配字数（摘要、方法、实验、局限、结论优先），每节保留开头。旧版只保留全文开头 60% 和结尾 40%，中间的方法和实验经常被整段丢掉。识别不到章节结构时仍退回首尾截断。
- **默认上限提高**：正文上限默认从 3 万字符提高到 10 万，超时默认从 60 秒提高到 300 秒（实测 3 万 token 左右的论文，部分模型需要 2–3 分钟）。仍是旧默认值的设置会自动升级，手动改过的值保留。
- **引用匹配更稳**：校验和坐标定位共用同一套规范化规则，忽略行末连字符断词、连字（ﬁ/ﬂ）、弯引号与直引号、空白和大小写差异。模型改了个别字词时，相似度 ≥ 90% 的引用会被替换为原文片段并标注“已按原文校正”；低于阈值或跨页的引用仍然跳过，不强行标注。
- **每个类别可标更多原文**：研究问题、方法、结果、局限各可附 0–2 条补充证据，同样经过原文校验、按类别颜色高亮，并显示在面板、导读索引、导读笔记和 Markdown 中。
- **增强批注 PDF 不再需要 Python**：改为在插件内部用 pdf-lib 写入高亮、下划线、中文批注、阅读指引、书签和导图附页。设置中的 Python 路径已移除。原 PDF、原书签、旋转和裁切框都保留。
- **自动更新**：`update_url` 指向 GitHub 最新 Release 的 `updates.json`，打包时自动生成并校验。

## 修复

- 缓存键加入模型、输出语言和提示词版本：切换模型或语言后会重新分析，不再返回旧结果。
- 首次返回非 JSON 时，重试请求有独立的完整超时，不再继承第一次已经消耗的时间。
- 支持 `response_format: json_object` 的服务会直接返回 JSON；不支持的服务明确拒绝该参数时自动去掉参数重发，并在本次运行中记住。其他 400 错误（如上游内容审核）不重发，避免重复扣费。
- PDF 文字层中错误映射的字形会变成控制字符（如 LoRA 论文中的“≪”变成 `\x1c`），模型逐字照抄后导致 JSON 解析失败。现在提取文字和解析 JSON 时都会清除。
- 任务说明改放在 user 消息中，并去掉角色设定：实测部分中转渠道会忽略或替换 system 消息。
- 常见错误附带说明：内容审核拒绝、密钥无效、余额不足、分组无该模型、上游不可用。
- 某一页读不到文字坐标（如插图页）时，不再导致整篇所有引用都定位失败。
- 关注点条数的兜底值与默认设置统一为 6（旧代码中一处兜底为 3）。

## 验证

- `npm run release`：8 个测试阶段全部通过（56 项纯函数、14 项集成冒烟、24 项导图/笔记、44 项修复回归、8 项 PDF 写入，以及回归脚本），XPI 打包与 `updates.json` 校验通过。
- 导出的 PDF 已用 PDF.js（Zotero 阅读器使用的引擎）解析验证：高亮/下划线的中文批注、颜色、外观流、原书签与新书签、导图附页均可正确读取。
- 2026-10-10 通过 CCG API 中转站，用三篇 arXiv 论文跑了真实分析流程（文字提取 → 按章节压缩 → 模型 → 原文校验 → 逐页定位）：

  | 模型 | Transformer（15 页） | LoRA（26 页） | GPT-4 技术报告（100 页，压缩到 10 万字符） |
  |---|---|---|---|
  | doubao-seed-2.0-lite（默认） | 13/13 校验通过，24 秒 | 14/14，26 秒 | 14/14，28 秒 |
  | gpt-5.6-terra | 上游 504 | 16/17，73 秒 | 上游 504 |
  | kimi-k2.6 | 17/17，109 秒 | 18/18，159 秒 | 18/18，132 秒 |
  | qwen3.8-flash | 15/15，67 秒 | 15/17，需重试，300 秒 | 上游内容审核拦截 |

  其中“校验通过”包括经模糊匹配替换为原文的引用；所有通过校验的引用都能唯一确定页码。
- **尚未在 Zotero 桌面端实际验收**。请按 README 第 9 节清单检查，重点是增强批注 PDF 导出（新的 pdf-lib 实现）和带补充证据的高亮。

依赖：esbuild 0.28.2、TypeScript 7.0.2、pdf-lib 1.17.1。
